# Security Policy

## Reporting a vulnerability

Email **security@crenoapp.com** with a description of the issue and, if
possible, steps to reproduce it. Please don't open a public GitHub issue
for anything that could be a real vulnerability.

We aim to acknowledge reports within **2 business days** and to have a
fix or mitigation plan within **7 days** for confirmed issues. We'll keep
you updated as we work on it, and credit you in the fix's changelog entry
if you'd like.

## Supported versions

Only the latest published version receives security fixes. Given how
young this package is, there's no long-term-support policy yet beyond
"upgrade to latest."

## Scope

In scope: this client library, and the Créno API it talks to
(`api.crenoapp.com`). Report Cloudflare/Stripe/Resend platform issues to
those vendors directly, not us.
